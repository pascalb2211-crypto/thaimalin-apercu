# Thaï Malin — site d'aperçu gratuit

Site statique (aucune installation) : accueil + 3 pages gratuites par mini-guide + présentation du hub « Mon voyage ».

## Mettre en ligne
1. GitHub : New repository → nom `thaimalin-apercu`, **Public**.
2. Envoie tout le contenu de ce dossier (y compris `.nojekyll`).
3. Settings → Pages → Branch `main` → Save.
4. Adresse : https://pascalb2211-crypto.github.io/thaimalin-apercu/

## Inscription e-mail (facultative)
Le formulaire « Être prévenu des nouveaux guides » reste caché tant que `config.js` est vide.

## Modifier
- Liens d'achat, prix, textes : `build_apercu.py` (à relancer) ou directement les fichiers HTML.
- Nouvelle édition : ajouter un guide dans la liste `G` du script.
