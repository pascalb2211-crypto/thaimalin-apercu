Infos pratiques et contact

Tout ce qu’il faut savoir avant et après l’achat.

🔑 Recevoir mon code

Juste après le paiement, un e-mail automatique t’envoie ton code d’accès et le lien du guide. Regarde aussi tes courriers indésirables.

📱 Utiliser mon guide

Le guide s’ouvre dans ton navigateur et peut s’installer sur l’écran d’accueil. Une fois ouvert, il marche aussi sans connexion.

⏳ Durée de l’accès

Une fois ton code entré sur un téléphone, l’accès reste ouvert 12 mois sur cet appareil (Édition 2026). Le code est valable le mois de l’achat et le mois suivant.

💳 Paiement

Le paiement est géré par Stripe (carte bancaire, et Apple Pay ou Google Pay selon ton téléphone). Thaï Malin ne voit jamais ton numéro de carte.

✉️ Une question, un problème de code ?

Écris à contact@thaimalin.fr en indiquant le guide acheté et l’adresse e-mail utilisée pour le paiement.
